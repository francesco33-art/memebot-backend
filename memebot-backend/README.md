# MEMEBOT backend (DEMO ONLY)
FastAPI + SQLAlchemy + scanner Solana + motore di paper trading. **Solo simulazione**: l'invio di transazioni Solana è bloccato tecnicamente, nessuna chiave privata o seed phrase.
Avvio: `pip install -r requirements.txt && uvicorn app.main:app --host 0.0.0.0 --port 8000`. Documentazione API: `docs/API.md`.
Deploy gratuito su Render: `render.yaml` (web service Free + Postgres Free, Francoforte).
